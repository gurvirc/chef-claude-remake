# Chef Claude V2
 
A full-stack, AI-powered recipe generator. Add the ingredients you have on hand, and Chef Claude suggests a recipe you can make with them. Sign up to save your favourite recipes and come back to them anytime.
 
This is a remake of my original Chef Claude project, rebuilt with a real backend, user accounts, and a personal recipe library, with more features like a **Macro Meal Builder** on the way.
 
 
## Features
 
- **AI recipe generation**: enter the ingredients you have and get a full recipe generated by an AI model
- **Recipe images**: each recipe is paired with a relevant food photo from Unsplash
- **User authentication**: sign up and log in with securely hashed passwords and session-based auth
- **Saved recipes**: save generated recipes to your personal collection, stored in a SQLite database
- **Markdown rendering**: recipes are displayed cleanly formatted with headings, lists and steps
### Coming soon
 
- **Macro Meal Builder**: set your protein, carb and fat targets and get meals built around them

## Getting Started
 
### Prerequisites
 
- [Node.js](https://nodejs.org/) (v18 or newer)
- A free [Hugging Face](https://huggingface.co/settings/tokens) access token
- A free [Unsplash](https://unsplash.com/developers) API access key
### 1. Clone the repo
 
```bash
git clone https://github.com/gurvirc/chef-claude-remake.git
cd chef-claude-remake
```
 
### 2. Install dependencies
 
Install the frontend and backend separately:
 
```bash
npm install
cd server
npm install
```
 
### 3. Set up environment variables
 
Create a `.env` file inside the `server/` folder:
 
```env
HF_ACCESS_TOKEN=your_hugging_face_token
UNSPLASH_ACCESS_KEY=your_unsplash_access_key
SESSION_SECRET=any_long_random_string
```
 
> **Note:** Never commit your `.env` file. It should already be listed in `.gitignore`.
 
### 4. Run the app
 
You'll need two terminals.
 
**Terminal 1: backend**
```bash
cd server
npm start
```
 
**Terminal 2: frontend**
```bash
npm run dev
```
 
Then open the URL Vite prints in your terminal (usually `http://localhost:5173`).

## How It Works
 
1. The user adds ingredients on the frontend.
2. React sends the ingredient list to the Express server.
3. The server builds a prompt and sends it to a model through the Hugging Face Inference API.
4. The generated recipe (in Markdown) is sent back, along with a matching image from Unsplash.
5. Logged-in users can save the recipe, which is stored in SQLite and linked to their account.
The API keys stay on the server, so they're never exposed in the browser.
